# Guest Desk SF

Local guest messaging and cleaner coordination for San Francisco hosts.

## Website files

This repository contains the complete static website, Rossni's supplied photo, the original SF illustration, and all eight Calendly booking links.

- `index.html` — content and SEO metadata
- `styles.css` — responsive styling
- `site.js` — copyright year
- `assets/` — portrait, illustration, and favicon
- `README.txt` — standalone setup notes included in the ZIP

## View or host

Open `index.html` locally, or upload this repository's root directory to a static website host. No dependencies, installation, or build command are needed.
